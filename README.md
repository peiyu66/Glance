# Glance

Glance 是個人 iPhone 視覺辨識試作：對準眼前的物品或文字，取得名稱、簡介與原文，並把圖片、結果和可用的參考連結保存在同一張卡片。也能從相簿選一張圖片辨識、回看紀錄及分享。

## 怎麼使用

完成資料使用同意與可用帳戶登入後，App 會顯示預覽。按「開始辨識」、對準目標並停穩，才會送出一張圖片；下一張需要再次操作。相簿選圖則在圖片載入、回到 App 後辨識一次。

切出 App、進入設定等情況會關閉鏡頭；連續開啟滿五分鐘或畫面持續近乎全黑也會停止相機。辨識可能失敗或中斷，低光與低紋理不保證清楚，也不會自動重送。完整條件見[鏡頭、相簿與辨識流程](docs/取景與辨識流程.md)。

## 圖片與隱私

Glance 保存實際送出的 JPEG 辨識副本及結果。相簿原圖不會被修改；刪除 Glance 紀錄不會刪除相簿原圖，也不能收回已分享或已送到服務端的資料。

圖片與辨識指令會送往 OpenAI。較新的開發版會自動以公開名稱查維基百科，有候選摘錄時再送一次文字 AI 核對；Google 查詢只在你點選連結時開啟。圖片中的人臉與文字沒有自動遮蔽。請先閱讀[資料處理、傳送對象與首次使用同意](docs/資料處理與首次使用同意.md)。

## 版本與限制

最後核實的公開安裝版是 **Build 43**；個人 Air 已安裝 **Build 60**。繁體百科標題修復 **Build 61** 已完成本機驗證與簽署、尚未安裝；背景完成與同卡刷新 **Build 62** 仍在測試，未發布。公開 43 沒有第二次 AI 核對，60／61 的百科補充會在非 active 時取消；62 的有限背景續行尚不可當作已安裝功能。詳[版本狀態與驗證範圍](docs/現況與版本.md)及[背景限制](docs/使用與設計/非active與第二階段取消.md)。

AI 可能辨識錯誤；名稱、條碼與百科連結不等於精確商品或個別物品已驗證。帳戶可用性與用量依實際支援，不能以個人帳戶的成功推論所有帳戶可用。
