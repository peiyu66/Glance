# 後續計畫與任務提案

日期：2026-10-09。範圍：個人 iPhone 原型。A 階段已於同日獲准並實作無帳戶探針，已在實機完成 2 秒／45 秒測試，直接切去系統瀏覽器的回呼僅在回到 app 後才處理，A 尚未通過；見 [A 實測紀錄](PHASE_A.md)。B–D 仍為提案，不能自動執行；[Roadmap](ROADMAP.md)保存整體關卡，[README](../README.md)說明目前可執行功能。

## 已完成基線

- SwiftUI iPhone Mock shell；正面、背面與移開為開發測試按鈕，不是正式辨識模式。
- 純 Swift 狀態核心：穩定約一秒觸發、同目標去重、晚回結果隔離、認回後才显示快取、背面獨立、移開隱藏、空結果靜默、退出前景清除。
- 原六項加上兩項合成回呼測試，共八項於 macOS host 全通過；Xcode 27.0 iPhone Simulator 編譯成功。
- 專用 iPhone 17 / iOS 27.0 模擬器已安裝、啟動，初始畫面已視覺核對；未做按鈕 UI 自動化。
- 公開 MIT repository 已建立。無相機、OAuth、模型目錄查詢、真實辨識或照片保存功能。

## 尚未解決的問題

最優先是 **官方 ChatGPT 方案在原生 iPhone 的可行性**。目前官方文件指定系統瀏覽器 OAuth PKCE 與 HTTP 127.0.0.1 回呼；未有本專案的實機證據可確認瀏覽器切換、app 生命週期和 callback listener 能可靠合作。這不等於已證明不可行，也不能視為已通過。

帳戶資格、可用模型、影像輸入能力、續期與撤銷都未驗證。`gpt-6-luna` 和 `reasoning.effort=none` 只是候選，必須在正式登入後以當前帳戶目錄與能力確認。除此之外，實際影像的穩定度與認回門檻尚未設計驗收；目前測試使用人為 target ID。

## 階段順序與驗收

| 階段 | 任務與範圍 | 通過標準 | 使用者操作／決策與停止點 |
| --- | --- | --- | --- |
| A：無帳戶原生回呼探針（建議下一項） | 做最小 iPhone 技術探針，先核對官方支援邊界，再以非敏感測試資料驗證系統瀏覽器與本機 HTTP callback 的生命週期；不連 OpenAI 登入、不保存 token | 指定實機能接到正確本機 callback，切換前景／取消／逾時可清理；記錄哪些只是測試回呼，不冒充正式 OAuth 成功 | 核准本階段；指定測試 iPhone、允許使用既有 Xcode signing team。若原生路徑不成立，報告原因並停止，不換付費 API 或遠端轉接 |
| B：正式 Pro 登入最小驗證 | 按最新官方流程實作 PKCE、state、nonce、身份驗證、scope 判定、帳戶模型目錄與安全本機會話；只做一次合成非敏感影像的最小辨識 | 實機正式 callback、身份與權限校驗通過；帳戶存在可用影像模型；一次影像結果成功；會話續期與登出／撤銷符合官方機制 | A 通過後另核准 B；使用者親自首次登入並同意具體的持續權限與本機憑證保留。不得擷取其他 app token。無資格、模型或正式支援即停止，不另收費 |
| C：相機與目標判定 | 串接本地取景、中央 ROI 穩定度、單張擷取、on-device 目標認回；先用 mock provider 驗證，再於已核准範圍串入 Pro provider | 持續穩定約一秒才出單張；移開立即隱藏；A→B 不掛錯；背面獨立；認回後使用既有結果；無逐格雲端傳送 | B 通過後另核准；首次相機權限由使用者授予，測試物件選非敏感素材 |
| D：個人原型驗收 | 在真實 iPhone 測物件名、OCR、條碼同時輸出、低光與反光、空結果、前背景切換；加入 UI 測試並量測延遲、用量、耗電 | 結果固定下方，未完成／未辨識／查無靜默；同目標無重送，晚回不誤掛；照片不持久化、敏感日誌為零；留下可重現測試與量測 | C 通過後另核准；依實測調整穩定时间、認回門檻與暫存容量。數值目標由基線量測後決定，不虛構零耗電或固定延遲 |

## 第一項可核准的任務

**提案 A：無帳戶原生回呼探針。** 限於最小技術程式、官方文件核對、編譯和指定 iPhone 的本機回呼測試；不實作完整相機 app、不開正式 OAuth 權限。成果是一份通過／失敗／未確認報告，足以決定是否進入 B。

需要的最小使用者操作是下一步是決定是否採 [A 實測紀錄](PHASE_A.md) 中的 Apple 系統認證視窗無帳戶探針；既有 signing team 已驗證且實機安裝成功。若新帳戶權限、持續 OAuth 或其他超出本階段的批准出現，先提出具體內容，不能擅自接受。後續 commit／push 範圍依該次核准指示，本文不授予日後無限自動推送。

成本以本機編譯和短時間實機測試為主，A 不消耗辨識模型額度；B 才會使用獲准的 ChatGPT 方案用量。若必要技術前提未成立即停止，避免先建完整 app。

## 固定界線

不新增 App Store 上架、商業化、分享、商品百科／資料庫、跨面整合或另付費 API。官方方式不可行時，回報阻礙供決策；不使用自訂協定假裝官方支援，也不以遠端轉接繞過限制。

## A 實測後的更新

直接切換系統瀏覽器的兩輪實機回呼都必須回前景才被接受；A 未通過，B 不啟動。建議後續 A2 改評估 Apple 系統認證視窗的生命週期，仍不使用帳戶或 token。取消／逾時及長登入流程未驗證；原 A 表中的完成標準仍有效，不能用已安裝或看到頁面替代。
