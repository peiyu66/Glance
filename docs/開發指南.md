# Glance 開發指南

本文件放在公開 repository，供開發與維護使用，不是私人文件。專案文件以繁體中文為主，保留必要的程式、API 與產品原名；README 保持用途、使用方式及重要限制，測試細節集中於本文件及各階段紀錄。

## 環境與建置

- 最低部署版本：iOS 17。
- 開發工具：Xcode 27，開啟 `Glance.xcodeproj`，使用 `Glance` scheme。
- 安裝到自己的 iPhone 時需自行設定簽署；憑證與帳戶資料不放入 repository。

模擬器建置可先確認程式整合，不需要裝置簽署：

```sh
xcodebuild -project Glance.xcodeproj -scheme Glance -sdk iphonesimulator \
  -configuration Debug -derivedDataPath /tmp/Glance-derived \
  CODE_SIGNING_ALLOWED=NO build
```

## 核心離線測試

在 repository 根目錄執行：

```sh
swift test --scratch-path /tmp/Glance-build
```

核心測試涵蓋授權與串流契約、穩定目標狀態、取消與晚回覆、有限快取、影像移動與品質、身份不確定性，以及請求限制。以本次命令實際結果為準，不把歷史測試數當成目前版本已通過的證據。

## 公開版本的工程啟動旗標

以下旗標可在 Xcode scheme 的 Run arguments 設定。各模式的驗證範圍不同：

| 旗標 | 用途與界線 |
| --- | --- |
| `--mock` | 原始按鈕操作的狀態示範，不能作為相機或登入驗收。 |
| `--camera-local-fixture` | 使用生成卡片測試 matcher 與控制器，不開真實相機、不向模型發送請求。 |
| `--camera-trial-once` | 使用一般取景介面，最多一筆影像請求；仍需由使用者按下開始。這是有界工程試驗，會涉及真實影像傳送。 |
| `--siwc-validation` | 帳戶驗證頁；登入、網路驗證與憑證操作應由本人依授權流程執行。 |

不要因為已有離線測試通過，就自動登入、開始取景或送出模型請求。尚未合併的本機工程旗標與功能不屬於本文件所述公開版本。

## 判讀結果與保護資料

模擬器、注入模型回應及生成卡片，只能支持各自覆蓋的程式路徑。它們不證明真實相機、實物匹配、原生登入、模型延遲、耗電或 UI 可讀性已通過。測試紀錄應寫明版本、環境、案例與限制，將離線通過、真機合成回放及本人實景分開記錄。

公開版本以中央取樣、穩定判斷、單筆在途與請求間隔限制處理影像；短期記憶有容量與時間上限。物件正反面目前視為不同目標，沒有跨面整合。相似標籤與影像對齊仍需實景驗證，不能保證所有相似包裝都可區分。

診斷只保留必要的狀態、次數、計時與安全錯誤類別。不要提交照片、實際辨識文字、token、帳戶識別資料、私有路徑或簽署素材；`.gitignore` 不是內容審查的替代品。

## 語言契約與後續驗收

產品目標是生成名稱使用台灣繁體中文，逐字辨識內容保留原文與數字。公開基底已有一般繁體中文名稱指示；本機後續版本正在補上明確 `zh-Hant-TW`、台灣用語及原文保留契約。離線測試可核對請求內容及解析不改字，但不能代替真實模型輸出的語言驗收。

「上次辨識」保留卡片也是後續開發中的顯示策略，本次文件提交不發布該功能。驗收完成後，應以實際合併版本更新 README 與本指南。
