# 開發指南

此份來源對應 Glance 0.1.0（70）；產品行為與驗證界線見[版本狀態](現況與版本.md)。本專案不提供作者簽署憑證、描述檔、帳戶或可通用安裝的 IPA。

## 工程結構

- `App/`：iOS SwiftUI 介面、相機、相簿選圖與正式 SIWC 登入。
- `Sources/GlanceCore/`：解析、查詢規劃、保存、分享及 OAuth 協定型別。
- `Tests/GlanceCoreTests/`：Swift Package 核心回歸。
- `Scripts/`、`Verification/`：隔離的測試工程與驗證工具，不是正式 App 的研究入口。
- `Config/Version.xcconfig`：版本來源；`Glance.xcodeproj` 的正式 scheme 為 `Glance`。

## 本機建置與測試

需要 macOS、相容 Xcode 與 Swift 6 工具鏈；部署目標依工程設定。OpenCV 依 `dependency-lock.json` 使用 `Scripts/prepare-opencv.py` 準備，保留 `ThirdParty/OpenCV` 的授權與聲明。該準備步驟會下載公開依賴，請先閱讀腳本。

```sh
swift test --jobs 2
python3 Scripts/prepare-single-capture-checks.py /tmp/glance-ui-fixture
```

第二步只產生隔離 Xcode 測試工程。開啟其 `CaptureFixture.xcodeproj`，選擇 iOS Simulator 執行所需測試；合成驗證不代表真相機、真登入或模型驗收。截圖重製另見[示意截圖](images/README.md)。正式裝置建置需設定自己的 Apple 開發團隊及簽署，不使用作者的個人裝置配置。

歷史原始資料測試是選用項；沒有指定 `GLANCE55_AUDIT_ROOT` 時會略過。不要為通過測試而取得他人的私人紀錄。

## AI 契約核對

[契約產生器](AI/Build69/產生器.swift.txt)以本地 Swift 核心組裝合成輸入，不呼叫網路。將其另存臨時 Swift 檔，連同 `Sources/GlanceCore/*.swift` 使用 `xcrun swiftc -O -parse-as-library` 編譯並執行，可與[已匯出契約](AI/Build69/實際契約.json)逐欄位比對。Build70 沿用此 P22／W5 契約；prompt 比對完整字串，schema 比對整棵 JSON，不只比版本號。

## 登入與資料界線

正式登入使用 SIWC 方案用量與 Responses API，不使用 API key 計費。真實 OAuth、模型請求及實機安裝各自需要操作者明確同意；不要將隔離 fixture 的成功等同官方服務已接受帳戶。測試資料與本機產物不得包含可用 token、私鑰、裝置識別或個人辨識紀錄。

[公開驗證摘要](驗證與建置/Build70公開驗證.md)記錄這次交付所沿用的證據及未執行範圍。此次 GitHub 同步沒有建立 IPA Release、改動歷史安裝頁或提交 App Store。
