# 資料處理與首次使用同意

適用 Build 60／61；同意版本為 **2026-10-19.1**。此頁依當前程式整理資料流；不是較早 Build 38／43 的傳輸說明，也不是對服務端保存政策的額外承諾。

| 步驟 | 接收方 | 傳送內容與觸發 |
| --- | --- | --- |
| 第一階段圖片辨識 | OpenAI | 本人按開始、重試保存圖片，或當次選圖成功後：JPEG、辨識指令與必要的條碼／QR 文字 |
| 百科候選蒐集 | 中文維基百科 | 第一階段完成後自動傳送經檢查的公開名稱／查詢詞；不送圖片、完整原文或人物佐證段落 |
| 第二階段語意核對 | OpenAI | 有可用候選後：第一階段名稱、簡介、選取的原文、搜尋實體及候選頁資訊／摘錄；額外一次文字 AI 請求，使用帳戶額度 |
| Google 搜尋 | Google／瀏覽器 | 只在本人點連結後傳送該查詢；不自動向 Google 查詢 |
| 分享 | 本人選擇的接收 App／對象 | 開啟當時的圖片與文字，或所選 JSON／診斷內容 |

第二階段 `input_version=2`，`raw_stage_one_json` 固定為 `null`。名稱、簡介、原文與搜尋實體仍在結構化 `stage_one` 中傳送；這不表示完全不送第一階段資料。完整原始回覆保留在本機診斷，沒有再次重複加入第二階段輸入。詳[完整契約](目前AI完整指令與Schema.md)。

## 相簿與可見內容

只讀取當次選定的一張圖片，縮小並重新建立 JPEG，不複製原檔附帶的拍攝位置、時間及相機資訊；圖片中的人臉、姓名、文件文字等可見內容仍保留。沒有送圖前的敏感內容遮蔽。

**相簿原圖不會被修改；刪除辨識紀錄也不會刪除相簿中的原圖。**

## 本機保存、JSON 與刪除

送出的圖片、辨識結果、參考資料及必要診斷保存在裝置。原始模型回覆可能含可見文字；JSON 診斷與分享可能包含這些內容，不應視為已去識別資料。歷史不自動補查或重送，已設定排除系統備份。

刪除只處理 Glance 本機紀錄及相關快取，無法收回已送往服務端或已分享的副本。OpenAI 與網站依其適用政策及帳戶設定處理收到的資料，App 無法承諾特定保存期限或訓練用途。

## 同意、帳戶與撤回

有效同意與帳戶就緒後才開放傳送。設定可重看說明、撤回同意及登出；撤回停止新傳送並取消尚未完成的百科工作，已送資料無法收回，本機紀錄仍可瀏覽刪除。可用模型與用量依實際帳戶支援，不能由既有個人 Pro 成功推論所有 Free 帳戶可用。

Build 59 將設定中的本機紀錄、相簿圖片、維基百科與 Google 搜尋放在同一區塊內，使用同級標題。傳輸說明已校正為減量後的第一階段結構化資料，同意版本未因純文案校正再次變更。
