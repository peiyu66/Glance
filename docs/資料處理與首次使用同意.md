# Glance 隱私聲明

更新日期：2026-10-27。適用 Glance 0.1.0（70）：每次最多兩個原文 Wiki 站、五候選，既有兩階段 AI；簡介如實顯示，不增加額外翻譯呼叫。正式 App 不保存 OAuth 原文診斷；AI 辨識 JSON 查看分享保留。見[版本狀態](現況與版本.md)。

Glance 在明確操作後辨識一張相機或相簿圖片，並在裝置上保存圖片副本、結果及參考連結。本頁沿用原「資料處理與首次使用同意」文件作為唯一隱私聲明入口；App 的首次使用與設定可查看資料傳送說明。

## 使用哪些資料

| 資料 | 用途與保存位置 |
| --- | --- |
| 當次相機圖片或選定相簿圖片的 JPEG 副本 | 送往 OpenAI 辨識；與結果一起保存在 Glance 本機紀錄 |
| 圖片內可見文字、辨識名稱、簡介、條碼／QR 文字與搜尋主題 | 產生結果、查詢參考資料與分享；其中必要內容依下節傳送 |
| 模型原始回覆、有限百科摘錄、來源連結與階段診斷 | 本機保存結果與排錯；JSON 檢視及主動分享可能包含辨識內容 |
| 紀錄識別、來源類型、圖片加入時間、嘗試開始／完成時間與狀態 | 維持同卡結果、歷史與錯誤恢復；保存在裝置 |
| 帳戶識別、服務提供的電子郵件（若有）、連線設定及授權憑證 | 驗證與維持 OpenAI 登入；保存在此裝置的 iOS Keychain |
| 同意版本、同意時間、首次設定狀態及顯示偏好 | 決定是否允許傳送與呈現設定；保存在裝置 |

相簿使用系統單張選擇器，只讀取當次選定圖片，不要求整個相簿的讀取權限。圖片會校正方向、縮小並重新編成 JPEG，不複製原檔附帶的拍攝位置、時間及相機資訊。**相簿原圖不會被修改；圖片中的人臉、姓名、文件文字等可見內容仍保留。** 目前沒有送圖前的敏感內容遮蔽。

## 傳給誰、何時傳送

| 步驟 | 接收方與觸發 | 傳送內容 |
| --- | --- | --- |
| 登入、維持會話與登出 | OpenAI 官方登入與授權端點；依登入、必要的既有會話續期或登出操作 | 必要的帳戶／授權與驗證資料；一般登入介面由 OpenAI 提供 |
| 第一階段圖片辨識 | OpenAI；按開始取得圖片、成功載入當次選圖，或明確重試保存圖片後 | JPEG、辨識指令與必要的條碼／QR 文字；請求使用登入授權 |
| 百科候選蒐集 | 維基百科官方語言站，依名稱選中文或原文站、每次最多兩站；第一階段完成後，存在合規公開名稱時自動查詢 | 經檢查的名稱／查詢詞；不附圖片、完整原文或用來確認人物的其他佐證段落 |
| 第二階段語意核對 | OpenAI；有可用百科候選時，額外一次文字 AI 請求 | 第一階段名稱、簡介、選取的畫面文字、搜尋實體與有限候選頁資料／摘錄 |
| Google 搜尋 | Google／瀏覽器；只在點選連結後 | 連結中的搜尋詞，商品搜尋可能包含本機可靠解碼的條碼 |
| 開啟其他連結 | 所選網站／瀏覽器；點選百科、完整隱私聲明或其他外部連結後 | 網址及一般瀏覽器連線資訊 |
| 分享 | 選定的接收 App／對象；明確操作分享後 | 當時選擇的圖片與文字，或 JSON／診斷內容 |

外語百科來源標示語言，點選後開啟實際原文頁，不強制轉為中文頁；送往第二階段的候選包含來源語言與原文摘錄。

接收服務也會收到 IP 位址等一般網路連線資訊。Google 不會在點擊前自動查詢。第二階段會使用帳戶額度；沒有合適候選就不送出，不會為讀取歷史而補送。

第二階段輸入中的 `raw_stage_one_json` 固定為 `null`，但名稱、簡介、選取原文與搜尋實體仍會傳送。完整原始回覆保留於本機診斷，沒有再次重複加入這個欄位；不能將 `null` 理解成完全不傳送第一階段資料。完整內容見[實際 AI 契約](目前AI完整指令與Schema.md)。

## 背景傳送與停止

在前景開始的一次辨識，切到背景後可能在系統給予的有限時間內繼續傳送；維基百科查詢及第二次文字 AI 請求也可能在背景才開始。鏡頭會停止；時間到期、撤回同意或其他停止條件會結束後續工作，不會自動重送。

切出 App 不等於立刻停止已開始的傳送。背景時間由系統決定，既有應用期限仍有效；不能保證一定完成。回到前景不自動重送或重開鏡頭；沒有活躍工作的未完成紀錄會在重讀時標為中斷。詳細行為見[背景辨識與中斷](使用與設計/背景辨識與中斷.md)。

## 本機保存與登入憑證

圖片副本、辨識紀錄及必要診斷保存在裝置，關閉 App 後仍保留，目前不依固定天數自動刪除。辨識歷史已設定排除系統備份；不能依賴這項設定作為備份或復原功能。

登入資料使用 Glance 自己的 iOS Keychain 項目，設定為此裝置、解鎖時可用，未啟用 Keychain 的 iCloud 同步。授權憑證用於官方授權及模型請求驗證，不加入圖片內容、百科查詢詞或辨識分享。Glance 不讀取其他 App 的登入憑證。

原始 JSON 與分享可能包含圖片中辨識出的個人資訊，不是已去識別的資料。分享內容由接收 App 決定處理方式；交出前應確認內容及對象。

## 刪除、撤回與登出

- **刪除一筆或全部辨識紀錄**：移除 Glance 內的紀錄、圖片副本及相關快取；不刪相簿原圖、已分享副本或服務端已收到的資料，也不等於登出帳戶。
- **撤回資料傳送同意**：停止新傳送並取消尚未完成的相關工作；已送出的資料無法收回。本機紀錄仍可瀏覽及刪除。
- **登出**：嘗試撤銷遠端可續期會話並清除本機授權憑證。若遠端撤銷未確認或本機保存失敗，App 會顯示提示；連線識別等設定可能保留。登出不等於刪除 OpenAI 帳戶、辨識紀錄或服務端資料。

刪除、保存或撤回若失敗，應依 App 顯示的結果處理，不能把按下按鈕當作已成功完成。

## 第三方政策與資料控制

OpenAI、維基百科、Google，以及開啟連結或分享時選定的服務，依各自適用政策與設定處理收到的資料。Glance 無法保證服務端特定保存期限、零保存、完全不訓練，或代為刪除第三方資料。適用條款可能因地區、服務與帳戶而不同，可由以下官方入口確認：

- [OpenAI 隱私政策](https://openai.com/policies/privacy-policy/)
- [Wikimedia Foundation 隱私政策](https://foundation.wikimedia.org/wiki/Policy:Privacy_policy)
- [Google 隱私政策](https://policies.google.com/privacy)
