# Build71 第二階段續做整合驗證

2026-10-27；本機來源整合清空歸零、W6 中文來源／搜尋名優先及單一位置的第二階段續做。正式簽署及 IPA 已完成，尚未安裝，不代表已提供公開安裝版。

## 行為及界線

- 未完成的第二階段：同一位置顯示帶驚嘆號的重試箭頭，短按只重查來源及執行一次文字核對，不新增第一階段 attempt、不變更原圖 UUID／原始 JSON。
- 進行中：同位置不定進度圓環，拒絕重複操作。完成的成功、no_match、insufficient_evidence 恢復整張重新辨識；無適用第一階段資料時也使用原整圖流程。
- 長按只開選單，取消不送出；選「重新辨識整張」才建立新第一階段。三按鈕尺寸維持既有一般 44×36／大字級 64×64，提示與無障礙標籤不限於顏色。
- 保存 optional runNumber，舊檔缺少時為第一代。新 run 以既有 runID／attempt 原子比對；遲到回覆不能取代新一輪、復活已刪卡片或使清空後編號失效。
- 進設定仍取消第二階段，返回／冷啟動不自動發送。第一階段在設定中完成時照常保存，之後可明確續做。本機取消不承諾遠端沒有執行或消耗額度。
- 修正兩個續做邊界：取消保存期間暫停新續做；尚未成功保存 run 的失敗不得在記憶體建立假的 runID，避免下次手動續做永遠比對失敗。
