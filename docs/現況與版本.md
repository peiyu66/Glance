# 現況與版本

更新：2026-10-27。公開產品基準為 **Glance 0.1.0（70）**，包含至 Build70 已完成的功能與修正。此次只同步原始碼、測試、文件及示意截圖，沒有建立新 IPA Release 或提交 App Store。

## 目前功能

- 單次相機辨識或選擇一張相簿圖片；歷史卡片、手動重送、圖片與文字分享。
- 第一階段以語意分出主體及相關實體；原語言 Wikipedia 有界檢索，最多兩站及五個候選。
- 第二階段核對來源與關係；P22／W5 要求中文簡介，App 如實顯示 AI 輸出，不作語言攔截或翻譯。
- 已保存的兩階段 AI 回覆及第二階段請求可查看、複製與分享；不補造舊紀錄未保存的內容。
- 付費帳戶及方案使用權限要求明示；網路、取消、逾時與憑證錯誤分別處理。正式 App 已移除研究登入續試、原文 OAuth 診斷及研究啟動入口。
