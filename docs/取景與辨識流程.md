# 取景與辨識流程

本機 Build71 整合中（尚未封裝）：原文 Wiki 加同條目中文候選，共用五名額，P22／W6 要求中文簡介；卡片及分享如實顯示 AI 結果。App 免費，但辨識需要相容 ChatGPT 付費方案與方案使用權限。見[版本及限制](現況與版本.md)。

## 開始與取得圖片

首次使用先閱讀並同意[資料處理說明](資料處理與首次使用同意.md)，再登入自己的帳戶。已有可用登入時不必重登；帳戶、方案及用量限制仍由實際可用狀態決定。

開啟預覽不會自行辨識。按「開始辨識」後對準目標並停穩約一秒，取得符合現有條件的一張圖才送出。等候超過三秒會顯示對應提示並繼續等候；取消或停止條件會結束這次等待。低紋理與暗光可能無法可靠判斷清晰度，並不保證每張送出的圖都清楚。

也可按「選擇相簿圖片」。選好一張、回到 App 並成功載入後會保存並辨識一次，不再按第二次開始。取消選圖不送出；尚在載入時切背景或載入失敗，不補送舊選擇。已完成選圖並保留的當次辨識，依有限背景規則續行。使用系統單張選擇器，不要求整庫權限。

相簿圖片校正方向、保留全圖比例、最長邊縮為 768，建立新的 JPEG。相機使用預覽的完整可見範圍，中央框協助瞄準。圖片上的人臉與文字仍會送出。

## 卡片與兩階段結果

處理時顯示此次送出的圖片。第一階段完成後，名稱、簡介、忠實原文與可用的 Google 搜尋先顯示並保存；不必等百科核對。下一張需要再次按開始或重新選相簿圖片。

Build65 的 P21 由第一階段按語意輸出獨立產品、品牌、製造商等實體，完整名稱不按空格拆詞；百科查詢與摘錄涵蓋各實體及可靠別名，仍由第二階段判斷關係。詳[兩階段設計](使用與設計/百科候選與兩階段.md)。

App 會為合規公開名稱查維基百科。有候選摘錄時，最多再發一次文字 AI 請求核對關係與補充簡介。第二階段更新同一張卡，保留原圖、第一階段解析與原始回覆。沒有合適來源、失敗或取消時保留第一階段。詳[兩階段設計](使用與設計/百科候選與兩階段.md)。

第一階段成功後即可使用分享及已開啟的 JSON 診斷入口，即使第二階段尚未完成。JSON 視窗與分享使用開啟當時的固定快照，不會在已開啟的分享內容中偷偷替換結果。再次開啟才取得當時最新資料。JSON 可能含辨識內容及診斷資訊，交出前應自行核對。

JSON 與分享之間維持單一操作位置：第二階段未完成且已停止時，帶驚嘆號的箭頭短按只續做第二階段；圓環表示處理中，不接受重複操作。第二階段完成（包含無匹配／證據不足）後短按才使用保存 JPEG 從第一階段重新辨識。長按可選「重新辨識整張」，長按與選單取消本身不送出請求。續做及整張刷新鎖定新的開始與相簿輸入。等待或失敗保留上次成功卡，新第一階段成功才替換，不混入舊百科來源。缺圖停用並說明原因。失敗／中斷卡仍可手動重試；不自動重送，也不在讀取舊卡時補查。

第一階段完成後圖卡、分享與 JSON 可用；操作按鈕的圓環仍反映第二階段工作是否進行中。沒有可用的結構化第一階段資料時，保留整張重新辨識，不提供假的續做入口。

Build63在「第2次嘗試」等提示旁顯示最後一次實際開始嘗試的本地日期時間。等待、失敗或重開App仍保留該時間，即使卡片顯示上次成功內容；原圖來源與加入時間不變。舊紀錄缺少可靠嘗試時間時只顯示次數，不以圖片時間或完成時間推算。

Build69 已撤除顯示語言預判。一般卡片與分享如實顯示原流程選中的 AI 簡介；若 AI 回外語也保留原文，不顯示缺少中文或語言回退提示。原有無有效第二階段時保留第一階段、contextual 合併、空值與失敗狀態維持。原文 Wiki、語言／關係、OCR、名稱及 JSON 不改寫。

## 歷史、預覽與停止

手動捲動歷史會收合鏡頭。符合目前閒置條件時，手動回到頂端會展開預覽，只等待下一次開始；程式捲動與資料更新不觸發辨識。「回到最新」只回頂，重新展開仍需新的手勢。

鏡頭連續開啟滿五分鐘會關閉，須明確重開。持續約一秒近乎全黑且無紋理也會停止相機，保留提示；已送出的第一階段仍保存結果。這些不是新的實景品質保證。

切到非active會關閉相機，但同次已保留的辨識可在系統給予的有限時間內續行整個兩階段；到期停止、不自動重送。回前景不自動重開鏡頭。設定、撤回、換帳戶、刪除與替換仍有各自的取消限制；單純捲讀歷史及近黑收合保留百科補充。詳[背景辨識與中斷](使用與設計/背景辨識與中斷.md)。

## 瀏覽、連結、分享與刪除

點縮圖可放大，原文可展開；每張卡的文字可長按選取，選取複製只涵蓋當張可見文字。整卡分享交出圖片與文字，接收 App 決定採用格式與預覽，不保證每個 App 的貼上結果相同。

Google 連結只有點選才開啟，保留完整搜尋文字與台灣地區參數，不限制網頁語言。商品查詢可能附上本機可靠解碼的單一合法商品條碼；Google 仍可能忽略條碼或部分搜尋詞，因此出現結果不等於找到同一商品。維基百科顯示實際來源頁及支持的關係；有同名或證據不足時不應把它當成精確商品確認。

支援明確 HTTP／HTTPS 網址點擊：條碼整值為合法網址時可點，名稱、簡介、原文與 JSON 內的明確網址亦可點。保留完整顯示、HTTP／HTTPS 與原始文字，只在點選後交給預設瀏覽器；不推定裸網域、電話或其他 scheme，不自動載入網頁預覽。條碼網址長按可複製原值；既有選取、JSON 與整卡分享內容維持。驗證範圍見[公開驗證摘要](驗證與建置/Build70公開驗證.md)。

可刪單筆或清除全部 Glance 紀錄。清空全部成功且儲存目錄確實清空後，下張顯示序號從 1 開始；失敗不重設、刪單筆不重排，資料 UUID 仍保持唯一。只移除 App 內的紀錄、圖片副本及相關快取，不會刪除相簿原圖、已分享副本或服務端已收到的資料。
